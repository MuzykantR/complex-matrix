# Матрицы комплексных чисел

Класс для работы с матрицами комплексных чисел и консольный калькулятор к нему.

## Запуск

```
cd src
javac *.java
java Main          # калькулятор
```

## Файлы

| Файл | Что в нём |
|-|-|
| `Complex.java` | комплексное число и операции над ним |
| `Matrix.java` | матрица и операции над ней |
| `MatrixSizeException.java` | кастомная ошибка |
| `Main.java` | точка входа (консольная утилита) |

## Операции

Базовые: сложение, умножение, деление, транспонирование, определитель (метод Гаусса).

Дополнительно: вычитание, обратная матрица (метод Гаусса–Жордана), эрмитово сопряжение,
умножение на комплексное число, степень, след, единичная матрица.

## Калькулятор

- Три ячейки для матриц — **A**, **B**, **C**. Результат любой операции можно сохранить в ячейку
  и использовать в следующей операции.
- Формат записи чисел: `1+2i`, `3-i`, `-2.5`, `4i`, `i`.

Пример получения `C = (A · B)T`:

```
> 1   A   2 2   1+i 2 0 i      ввести A
> 1   B   2 2   1 i i 1        ввести B
> 5   A B   C                  A * B, сохранить в C
> 9   C   C                    транспонировать C
```
